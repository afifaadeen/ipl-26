# **IPL – Fantasy Cricket League**

### **1. Description**
A backend application for a fantasy cricket platform where users create fantasy teams, join contests and earn points based on cricket player performances.

### **2. Technologies Used**
- Python
- FastAPI
- SQLite
- SQLAlchemy
- JWT Authentication
- Argon2 Password Hashing
- Docker
- AWS EC2
- Docker Hub
- GitHub Actions

### **3. RBAC**
- **Admin:** Manages organizers and platform data.
- **Organizer:** Manages players, tournaments, contests and match statistics.
- **User:** Creates fantasy teams, joins contests and views rankings.

### **4. API Requirements**

The project contains **18 APIs**.

**Authentication APIs:**

- A1 – Register
- A2 – Login
- A3 – Refresh Token

**Project APIs:**

- E1 – Create Organizer Account
- E2 – Add Cricket Player
- E3 – Get All Players
- E4 – Get Player Details
- E5 – Create Tournament
- E6 – Get All Tournaments
- E7 – Create Fantasy Team
- E8 – Add Player to Fantasy Team
- E9 – Remove Player from Fantasy Team
- E10 – Get User's Fantasy Teams
- E11 – Create Contest
- E12 – Join Contest
- E13 – Publish Player Statistics
- E14 – Get Contest Leaderboard
- E15 – Get Fantasy Points History
